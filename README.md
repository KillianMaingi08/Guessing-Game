# Number Guessing Game (Java)

## About
A simple, interactive number guessing game built with Java and `JOptionPane`. The program generates a random number within a user-defined range, and the player keeps guessing until they find the correct number.

## Features
- User-defined minimum and maximum numbers.
- Random number generation.
- Feedback for guesses that are too high or too low.
- Tracks the number of attempts.
- Pop-up input and message dialogs using `JOptionPane`.

## Technologies Used
- Java
- Java Swing (`JOptionPane`)

## What I Learned
- Generating random numbers using the `Random` class.
- Accepting and converting user input using `Integer.parseInt()`.
- Using `do-while` loops and `if-else` statements.
- Displaying graphical input and output with `JOptionPane`.
- Counting attempts using variables.
